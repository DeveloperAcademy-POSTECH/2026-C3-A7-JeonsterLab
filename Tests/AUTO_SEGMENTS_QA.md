# Mac Auto Segments — 2026-09-09

## 동작 및 저장 계약

- Mac 녹화 편집 화면의 **Suggest Segments**로 명시적으로 분석한다. 수신 즉시 자동 실행하거나 Watch 녹화를 시작/중지하지 않는다.
- 후보는 차트의 옅은 영역/점선과 접을 수 있는 목록에 표시된다. 목록 또는 차트 영역 클릭으로 선택하고, 기존 차트 핸들로 경계를 조정한다.
- **Confirm Segment** 이후에만 기존 스냅 목록에 `Auto · Confirmed`로 들어간다. 초기 라벨은 Unlabeled이며 기존 라벨/메모/폴더 편집 기능을 사용한다.
- 미확정 후보는 `workingSnapEvents`에 포함하지 않는다. 따라서 후보 자체를 데이터셋으로 내보내지 않는다.
- 후보/확정/기각 상태는 각 녹화의 `label.json`에 저장한다. 원본 CSV, 메타데이터, 기존 flip 분석 JSON은 수정하지 않는다.
- 확정 구간은 기존 로컬 편집 구간 배열에 저장하고 고유한 `autoSegment` 출처를 사용한다. 기존 자동 flip ID와 충돌하지 않는다.
- 재분석은 기존 후보 ID/겹치는 후보를 중복 추가하지 않고, 확정·기각 상태를 유지한다. 기존 저장 구간과 겹치는 새 후보는 추가하지 않는다. 수동 라벨/메모/경계를 덮어쓰지 않는다.
- 확정/기각/분석 결과 저장 실패 시 패키지 바인딩을 바꾸지 않고 오류를 표시한다.
- 분석은 백그라운드 작업이며 취소, 화면 이탈 및 녹화 전환 시 결과를 적용하지 않는다.

## 감지기 v1의 범위

가속도 벡터 크기(g)와 회전 속도 벡터 크기(rad/s)를 사용한다. 활동 종류나 반복 횟수를 분류하는 모델이 아니다.

- 점수: `max(acceleration / 0.08, rotation / 0.6)`.
- 실제 시간 간격을 사용하는 0.08초 EMA 평활화. 시작 점수 1, 유지 점수 0.5의 다른 문턱값으로 경계 흔들림을 줄인다.
- 최소 활성 지속 시간 0.25초, 안정 구간 0.4초 후 종료, 앞뒤 최대 0.12초 여유.
- 0.25초보다 큰 샘플 간격 및 유효하지 않은 센서 값에서 구간을 끊는다. 증가하지 않는 시간 값은 오류 처리한다.
- 최대 후보 2,000개 후 중단하고 제한 안내를 표시한다.
- 긴 연속 동작은 하나의 후보일 수 있다. 걷기의 매 걸음이나 의미상 한 루틴을 정확히 알아낸다는 보장은 없다.
- 고정 문턱값보다 작은 움직임은 누락될 수 있다. 합성 데이터 검증만으로 실제 모든 활동에서 정확하다고 주장하지 않는다. 수동 선택은 계속 제공한다.

## 직접 UI 검사

실제 sandbox entitlement로 ad-hoc 서명한 Mac Debug 앱에서, 사용자 녹화와 분리된 합성 프로젝트를 열어 확인했다.

- 20초/1,000샘플의 세 활동 구간에서 후보 3개(1.90–4.26, 7.90–10.28, 13.90–16.26초) 표시.
- 첫 후보 목록 선택 → 차트 확대 및 Suggested Segment 인스펙터 표시.
- 차트 끝 경계를 4.26초에서 4.01초로 조정 → Confirm Segment → 저장 스냅 1개와 `Auto · Confirmed` 표시.
- 확정 구간에 Walk 라벨과 `Auto segment QA` 메모 입력.
- 두 번째 후보 기각 → Analyze Again → 확정 구간 1개, 대기 후보 1개 유지. 기각한 후보가 다시 나타나지 않음.
- 선택 해제 후 차트의 세 번째 후보 영역을 직접 클릭 → 올바른 후보와 13.90–16.26초 인스펙터 선택.
- 1080px 창 너비에서 라이트/다크 후보 목록 및 인스펙터 확인. 구간 목록은 접거나 스크롤할 수 있음.

직접 UI에서 프로젝트 재열기까지는 수행하지 않았다. 저장/ZIP 재개의 검토 상태 보존은 위 모델/서비스 회귀 검사로 검증했다.
실제 여러 활동의 센서 데이터로 오탐/누락과 경계 품질을 추가 검증해야 한다. iPhone/Watch UI와 배포 설정은 이번 기능에서 변경하지 않는다.
