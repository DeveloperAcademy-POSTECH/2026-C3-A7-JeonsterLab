## Mac 실제 앱 확인

최종 Debug 앱에 실제 sandbox entitlement를 적용하여 ad-hoc 서명한 뒤 실행했다.
실사용 데이터 삭제/이동 없이 생성된 별도 프로젝트에서 다음을 수행했다.

- 최초 튜토리얼 3단계의 Back/Next/Get Started 및 빈 작업 공간 확인.
- 최소 창 크기(관찰된 외곽 크기 1080 × 732)에서 라이트/다크 차트, 인스펙터, 사이드바 확인.
- 컨테이너 밖 임시 폴더의 `.watchmotion` 파일을 시스템 Open 패널로 열고 세 축 파형 표시 확인.
- 5.21–11.11초 수동 구간 저장, Walk 라벨 선택, 메모 저장 확인.
- 프로젝트 라벨을 Walk QA로 변경하고 기존 구간의 라벨과 메모가 유지되는지 확인.
- 기존 구간과 겹치는 선택의 경고/저장 비활성화, 겹치지 않는 선택의 저장 가능 상태 확인.
- General/Export 설정의 라이트·다크 레이아웃, 내보내기 파일명 미리보기 확인.
- 시스템 Save 패널로 컨테이너 밖에 프로젝트 내보내기 성공. ZIP 무결성 검사 통과.
- 내보낸 프로젝트를 다시 열어 라벨, 메모, 저장 구간 복원 확인.
- UI Dataset 폴더 생성, 저장 구간 추가, 1개 구간 표시 확인.
- CSV 옵션 시트의 라이트·다크 레이아웃 및 Cancel 확인. 버튼 잘림/겹침은 관찰되지 않음.
- CSV 실제 내보내기 성공: 헤더 1행 + 선택 구간 295행.
- 폴더를 포함한 프로젝트를 내보내고 최종 수정 빌드에서 재개하여 폴더 구성과 저장 구간 유지 확인.
- 검증 후 Mac 앱의 화면 테마를 검증 전 Light로 복원.

## iPhone / Watch 시뮬레이터 확인

- iPhone 17e / iOS 26.5: 녹화 목록, 상세 정보, 가속도→자이로 센서 전환과 단위 표시 확인.
- 연결되지 않은 상태에서 Mac 전송 버튼 비활성화, 연결 설정/도움말 접근 확인.
- 라이트·다크 연결 설정과 상세 화면 확인.
- 시뮬레이터의 Preferred Text Size를 5단계 증가시켜 설정 문구 줄바꿈, Done 버튼, 상세 화면의 메뉴형 센서 선택, 차트 범례와 메모 접근 확인.
- 스크롤 영역의 접근성 Scroll Down 액션으로 하단 연결 도움말/전송 컨트롤에 도달함을 확인. 전체 VoiceOver 사용성 검증은 아님.
- iPhone 글씨 크기와 테마는 검증 전 상태로 복원.
- SE 3 (40mm) / watchOS 26.5: DEBUG 녹화 중 미리보기에서 긴 타이머, 샘플 수, Stop 버튼이 화면에 들어오는지 확인.
- Watch 미리보기는 고정된 4,150샘플과 무동작 버튼을 사용한다. 실제 센서 수집, Stop 실행, 이번 빌드의 대기/보관 목록 화면 및 Watch 큰 글씨 검증으로 간주하지 않는다.

이번 변경은 Mac UI와 테스트 자료에 한정된다. iPhone/Watch는 이번에 다시 archive하지 않았다.
최종 Mac 빌드에는 AppIntents 미사용에 따른 메타데이터 추출 생략 경고만 관찰되었다.
명령행 회귀 검사는 XCTest UI 자동화나 전체 기기 통합 검사를 대체하지 않는다.

## 아직 필요한 출시 전 검증

1. 실기기 Watch → iPhone → Mac 전체 흐름, 권한 거부, 앱 백그라운드 전환/잠금, 연결 끊김, 재전송, 재시작 및 원본 보존.
2. Watch 실제 녹화/중지/보관 목록 조작과 접근성 글씨 크기, 전체 VoiceOver 흐름. iPhone 모든 접근성 크기/화면을 전수 확인한 것은 아님.
3. Create ML 내보내기 실제 UI 흐름, 대용량 프로젝트 작업 취소/디스크 부족, 선택 핸들 리사이즈 등 이번에 직접 수행하지 않은 경계 조건.
4. 배포 인증서/provisioning을 적용한 archive Validate, 실제 TestFlight 설치 및 App Store Connect 메타데이터/개인정보 답변 확인.

빌드 및 확인한 UI 흐름은 통과했지만, 이 결과는 App Store 심사 승인 보장이 아니다.
Watch는 현재 앱을 열어 둔 상태에서 녹화하며, 백그라운드 지속 녹화를 지원한다고 안내하면 안 된다.
