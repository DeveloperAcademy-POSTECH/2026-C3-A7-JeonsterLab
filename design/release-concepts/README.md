## Generation prompts

### dark-type

Use case: ui-mockup with logo-brand exploration. Create one highly polished wide landscape design concept presentation for the real macOS app "WatchMotion Editor", a professional tool for editing Apple Watch motion recordings, labeling motion segments and exporting datasets. This is a raster design proposal, not a screenshot of implemented software. Composition: ONLY one large standalone rounded-square app icon on the left 23% with a small tasteful concept label and exact brand name beneath; on the right 73% one complete front-facing Mac application window, crisp perfectly straight-on flat UI, no laptop hardware, no perspective, no desk, no device photography, no extra mockups. Give the application window most of the visual space, legible carefully typeset UI. Native macOS traffic-light window controls and coherent desktop toolbar. App content: left sidebar for Projects, Recordings, Folders; selected recording "Walking · Session 04"; large central timeline showing realistic tri-axis acceleration traces in X Y Z, a selected time range with handles and quiet vertical grid, separate smaller gyroscope plot, bottom segment list with start/end time and labels "Walk", "Turn", "Rest"; right inspector shows selected segment "00:12.40 – 00:16.80", label selector, Save label. Top toolbar has Import and Export dataset. Small device connection status in sidebar footer. Charts are motion sensor traces NOT financial charts or audio DAW waveforms; no finance, currencies, crypto, promotional cards, fake AI features. Use restrained English UI labels for legibility. Beautiful spacing and information hierarchy, believable usable editor, understated rich materials. Exact brand spelling "WatchMotion Editor". All logo artwork must be original, never copy Coinbase, Sui or any reference brand marks. The user supplied inspiration references: navy dashboard with subtle electric blue atmospheric glows; a white minimal logo on black with blue overhead glow; bold white editorial typography on softly grainy black; light dashboard with black sidebar. Interpret their mood for an original motion editing app. Concept 01 "DARK TYPE": typography-led identity. App icon is near-black soft square with an exceptionally strong custom white WM ligature, W and M cleverly sharing diagonal strokes suggesting motion, bold compact memorable and readable at small size. No full tiny app name inside icon. Left brand lockup below icon plays with "WatchMotion" and "Editor" stacked in expressive but disciplined bold Swiss grotesk typography. Monochrome graphite UI with off-white type, cool gray surfaces, very restrained ice-blue selection accent; dense professional creative software feel. Fine grain only on presentation background, all UI crisp. Subtle white peripheral light on charcoal like the supplied black/white typographic reference. Top label "01 / DARK TYPE".
