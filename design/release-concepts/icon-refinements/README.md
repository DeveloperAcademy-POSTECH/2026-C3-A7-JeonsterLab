# Waveform icon refinements

Built-in image generation tool; three visual proposals based on the user-supplied black icon with coral brackets and a white waveform. Not installed in app asset catalogs.

User UI direction: prior Dark Type editor for dark mode, Precision Cut editor for light mode. Implementation pending.

## Prompts

### 01-soft-ripple

Use case: logo-brand, edit an existing app icon. Reference image is the exact design to refine. Produce ONE standalone high-resolution square app icon, front-facing, centered, no text, no labels, no UI, no comparison board. Preserve the reference identity: near-black subtly shaded rounded-square tile, coral-red square selection brackets on left and right, central white waveform floating between brackets. Show the complete icon with a narrow consistent light-neutral exterior margin, no cropping of corners, tiny restrained shadow. Brackets must remain symmetrical and visually close to original, not parentheses. Modify primarily the white central curve: retain the original flowing silhouette but add just a little realistic sampled motion signal detail, irregular secondary undulations. It should read as a motion-data waveform rather than one perfect sine wave. Keep it bold and legible at app icon sizes; white line with consistent medium-bold weight and rounded joins, no tiny hairlines, no noise cloud, no duplicate traces, no grid, no axes, no text. Avoid ECG/heart-rate spike clichés and equalizer bars. Keep white waveform well inside brackets with generous separation. No new colors, no watch illustration, no letters. Variant 1, subtle refinement: preserve a broad valley at left, a broad central crest, and a fall and slight lift at right as in source. Add only 3–4 very small soft rounded ripples along this main curve, especially the climb and descent. 85 percent original smoothness, 15 percent natural recorded motion texture. Understated refined flowing signal. Closest to reference.
